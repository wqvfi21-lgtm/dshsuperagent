# dshsuperagent

Target repository for the dsh-superagent agent running in DeepSeek Harness (desktop profile).

## How to use

- The agent only acts when someone on its allowlist asks.
- Ask with a comment: `@<agent-login> <request>` on an issue.
- Work arrives as pull requests opened by the agent account.

## Status

Initialised so the repository has a default branch the agent can clone and branch from.
